# COLOR-SWITCHER

## English

### Description
A web-based project demonstrating different methods of interacting with and changing the background color of a webpage. The project consists of three main components:

1.  **Cyclical Color Switcher**: A button that iterates through a predefined list of colors (defined in a JavaScript object), changing the background and displaying the color name and hex code on each click.
2.  **Individual Color Pickers**: Multiple buttons, each assigned a specific color. Clicking a button immediately changes the background to the corresponding color and updates the information display.
3.  **API-Driven Color Switcher**: A feature that fetches a random color from an external API (csscolorsapi.com) and applies it to the background.

---

## Čeština

### Popis
Webový projekt demonstrující různé způsoby interakce a změny barvy pozadí webové stránky. Projekt se skládá ze tří hlavních částí:

1.  **Cyklický přepínač barev**: Tlačítko, které prochází předdefinovaným seznamem barev (definovaným v JavaScriptovém objektu). Při každém kliknutí změní barvu pozadí a zobrazí název barvy a její hexadecimální kód.
2.  **Přepínače jednotlivých barev**: Více tlačítek, z nichž každé má přiřazenou konkrétní barvu. Kliknutím na tlačítko se barva pozadí okamžitě změní na odpovídající barvu a aktualizují se zobrazené informace.
3.  **API přepínač barev**: Funkce, která načte náhodnou barvu z externího API (csscolorsapi.com) a aplikuje ji na pozadí stránky.
